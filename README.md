# Алексей Громов — сайт-резюме

Статичный сайт на [Astro](https://astro.build), выкладывается на GitHub Pages: https://tamn3633.github.io

Код сайта, как и код моих сервисов, собран с ИИ-агентами: моя часть — постановка задачи, проверки и приёмка.

```bash
npm install
npm run dev     # локально
npm test        # тесты гейта приватности
npm run check   # сборка + гейт приватности
```

Тексты и цифры — в `src/data/profile.json` и `src/content/cases/`, вёрстка — в `src/pages/` и `src/styles/`.
